# OAG college

A specification for a knowledge commons: free knowledge for all, preserved and
available forever in the strongest practical sense. It may support learning
paths, explanations, evidence, discussion, and contribution, but knowledge
should not depend on one institution, one owner, one paid subscription, or one
fragile server.

## Current state

Initial baseline only. No curriculum, knowledge format, preservation system,
license policy, or service has been selected or validated. The operator's request
is preserved in [`OPERATOR-INTENT.md`](OPERATOR-INTENT.md).
