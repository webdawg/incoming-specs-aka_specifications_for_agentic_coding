# Agent entry point

Read the parent `AGENTS.md`, then this folder's `OPERATOR-INTENT.md`, `README.md`,
`SPEC.md`, and `RESEARCH.md` before contributing.

This is an independent specification project. Keep its education, knowledge,
preservation, access, and continuation artifacts inside this folder. Preserve the
operator request verbatim and distinguish requirements, proposals, observed
behavior, inferences, and unknowns.

The purpose is free knowledge for everyone, indefinitely. Do not turn education
into a paywall, a hidden gate, a single institution's private control, or an
opaque system that cannot be inspected, copied, preserved, translated, or
challenged. Respect authorship, licensing, safety, privacy, accessibility, and
legitimate takedown requirements while keeping the knowledge commons broadly
available.

Do not implement or deploy anything as part of this baseline. Use synthetic
examples where needed, protect private information, preserve concurrent work,
and inspect exact diffs before publication.
