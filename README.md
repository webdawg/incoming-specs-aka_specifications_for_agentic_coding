# Incoming Specs — Specifications for Agentic Coding

A collection of independent specifications for agentic coding work. Each project
owns a named folder containing its requirements, research, developer documentation,
and continuation state. This repository is not dedicated to a single specification.

## Specifications

| Folder | Purpose | State |
| --- | --- | --- |
| [oag-developer_understanding](oag-developer_understanding/README.md) | Reverse-build detailed developer understanding of the six Open Agent Graph family repositories. | Baseline plus first source-inspection pass; incomplete. |
| [oag-location-to-legacy](oag-location-to-legacy/README.md) | Location-linked chats/alerts, live plain-text access, Android client and encrypted groups with limited availability. | Initial baseline; research and design decisions pending. |

See [AGENTS.md](AGENTS.md) before contributing. Keep each project's artifacts
inside its own folder; add new independent specifications as sibling folders.
