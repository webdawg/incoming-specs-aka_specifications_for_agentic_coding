# OAG vote

A specification for human decision support: people must be able to understand
choices, participate meaningfully, and decide matters themselves. The system may
organize proposals, evidence, discussion, eligibility, ballots, counting, and
results, but it must not quietly replace human judgment with an agent's decision.

## Current state

Initial baseline only. No voting implementation, governance model, or decision
procedure has been selected or validated. The operator's request is preserved in
[`OPERATOR-INTENT.md`](OPERATOR-INTENT.md).
